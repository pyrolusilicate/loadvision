# Документация Loadvision

Запуск сервиса и полный список команд находятся в [корневом README](../README.md). Здесь лежат
подробности.

## Если нужно разобраться в проекте за полчаса

1. [../README.md](../README.md) рассказывает, что это за сервис, какие у него числа и как его
   поднять.
2. [architecture.md](architecture.md) объясняет устройство, слои, сущности и каталог ошибок.
3. [features.md](features.md) описывает, что сервис умеет сверх прогноза, а именно отказ
   отвечать на неподходящем кадре, сверку с нормативным отчетом, оценку веса и карты внимания.
4. [ml/model.md](ml/model.md) показывает, что внутри поставляемой модели и почему выбрано
   именно это.
